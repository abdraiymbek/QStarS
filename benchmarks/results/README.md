# Retained simulation and validation evidence

`2026-09-28/` contains complete selected example runs, a final convergence
campaign, independent published structure sequences, and two failed/rejected
approaches. Source snapshots and original metadata are preserved, including
the recorded dirty state. Original timestamped local runs are also retained
under the repository-root `results/` directory, which is not tracked in Git.

These artifacts record what ran; they are not all successful or scientifically
validated models. Read `termination.json`, `validity_warnings.json`, and, for
the interrupted trust-region investigation, `stop_context.json`.

The early archived source registries contain a subsequently retracted suspicion
about Hassan's Eq 6. **Report 4 and the current source registry supersede that
interpretation.** The implemented cubic root was correct; a new regression
confirms its equivalence to the printed trigonometric expression. Archived
snapshots are not rewritten to erase the audit history.
